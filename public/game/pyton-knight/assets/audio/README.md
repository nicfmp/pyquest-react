# Áudio original V5

`ambient.wav`: composição instrumental original de 32 segundos, com drone suave,
acordes e notas espaçadas. Loop contínuo, mono PCM 16 bits / 22.050 Hz.
Os outros seis WAVs são sinais originais para interação, coleta, mecanismo,
portal, dano e conclusão. Não contêm voz, samples ou material externo.

Fonte: `tools/v5/generate-audio.py`, criado durante a implementação da V5 em
22/09/2026. Geração determinística usando somente a biblioteca padrão Python.
Regenerar com `python tools/v5/generate-audio.py`.
